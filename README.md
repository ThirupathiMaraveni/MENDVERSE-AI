🧠 MENDVERSE AI

An intelligent AI-powered platform that identifies physical objects from images and provides useful information and problem analysis.

🚀 About the Project

MENDVERSE AI is an AI-powered application designed to identify physical objects from uploaded images and help users understand potential problems related to them.

The platform uses artificial intelligence and computer vision capabilities to analyze images, recognize visible objects, and generate meaningful descriptions.

Our goal is to make object identification and problem analysis easier, smarter, and more accessible.

✨ Key Features

- 📸 Image Upload: Upload images for AI-powered analysis.
- 🔍 Object Identification: Identify the main physical object visible in an image.
- 🤖 AI-Powered Analysis: Generate intelligent descriptions using AI.
- 🧠 Vision Intelligence: Analyze visual information using a vision-capable AI model.
- 💡 Problem Analysis: Help users understand potential issues related to identified objects.
- ⚡ Interactive Interface: Simple and user-friendly application experience.

⚙️ Installation & Setup

1. Clone the Repository

git clone https://github.com/ThirupathiMaraveni/MENDVERSE-AI.git

2. Navigate to the Project

cd MENDVERSE-AI

3. Create a Virtual Environment

python -m venv .venv

4. Activate the Environment

Windows:

.venv\Scripts\activate

5. Install Dependencies

pip install -r requirements.txt

6. Install and Start Ollama

Download Ollama:

https://ollama.com/

Make sure the vision model required by the application is downloaded and running.

7. Run the Application

python app.py

Use the appropriate launch command if your application uses a framework such as Streamlit or Flask.
